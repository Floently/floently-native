# Floently Read iOS

Native iOS rebuild of Floently Read.

Stack:

- Swift
- SwiftUI
- UIKit where needed
- PDFKit where useful
- AVFoundation for audio
- URLSession for upload/background-capable networking
- FileManager cache
- StoreKit 2 for subscriptions later

Goal:

- Premium Read UI
- Import without dead spinner
- First readable text quickly
- First audio-first playback
