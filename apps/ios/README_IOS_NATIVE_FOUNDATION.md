# iOS Native Foundation

This is the first native iOS foundation for:

- Floently Learn
- Floently Read
- Floently Create

It defines:

- Shared SwiftUI design primitives
- Product-specific palettes
- Learn skeleton
- Read skeleton
- Create shell

These files are not yet full Xcode projects. Next step is to generate buildable Xcode project structures or package them for local Xcode creation.
