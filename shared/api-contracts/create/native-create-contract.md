# Native Create API Contract

## Goal

Create will be native later, but initial shell should be planned now.

## Initial Create shell

Native Create initial shell needs:

- landing
- login/account shell
- project dashboard placeholder
- coming soon/waitlist state
- subscription/access placeholder

## Future backend API surface

Future Create needs:

- projects
- assets
- templates
- timeline
- export jobs
- billing/access

Target namespaces:

- /api/v1/create/projects
- /api/v1/create/assets
- /api/v1/create/timeline
- /api/v1/create/export-jobs
- /api/v1/create/templates
- /api/v1/create/billing
