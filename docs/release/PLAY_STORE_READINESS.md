# Play Store readiness

## Current app identity

- App name: Floently

## Store positioning

Floently is a native learning and productivity suite with separated product access for Learn, Read, and Create Studio.

- Floently Learn: Finnish learning, YKI practice, professional Finnish, roleplay, cards, progress, and account.
- Floently Read: import or paste text/URLs, detect language, generate reading content, and read automatically by default.
- Floently Create Studio: direct creation tools for hooks, captions, summaries, repurposing, and brand brain outputs.

## Listing draft

### Short description

Native Finnish learning, reading, and creation tools in one Floently suite.

### Full description draft

Floently brings learning, reading, and creation tools into one native Android suite.

Floently Learn helps learners practise Finnish with YKI-oriented tasks, professional Finnish, roleplay, cards, progress tracking, and account access.

Floently Read is designed for reading workflows. Paste text or a URL, detect language, generate a reading session, and continue with read automatically enabled by default.

Floently Create Studio gives direct creation tools for hooks, captions, summaries, repurposing packs, and brand brain style outputs.

Learn, Read, and Create are separated products with separate access checks. Bundle access can be added later, but the products should remain clear and separate.
