# KieliValmis Native Rebuild Rules

The next-generation KieliValmis Learn line is governed by the following documents:

1. `../LEARN_NEXT_GENERATION_GOVERNING_RULE.md` — clean parallel rebuild, polyglot ownership, state/data authority, cutover rules.
2. `KIELIVALMIS_CARD_AND_LAYOUT_SYSTEM_V1.md` — card families, dimensions, alignment, spacing, responsive rules.
3. `KIELIVALMIS_HOME_BLUEPRINT_V1.md` — first native screen blueprint.
4. `ILOADI_UI_CONSTITUTION.md` — suite-wide visual principles.
5. `ILOADI_DESIGN_TOKENS.md` — canonical tokens.
6. `ILOADI_COMPONENT_SPEC.md` — shared component geometry.
7. `ILOADI_DESIGN_CHANGE_GATE.md` — versioned design-system change process.

When older parity documents conflict with a clean visual redesign, `LEARN_NEXT_GENERATION_GOVERNING_RULE.md` controls: required capabilities may not be silently lost, but old screen geometry and source structure are not preserved for their own sake.
